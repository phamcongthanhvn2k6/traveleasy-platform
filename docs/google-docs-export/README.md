## 🚀 Hướng dẫn Copy & Dán vào Google Docs
1. Mở file `.docx` tương ứng trong máy bằng Word (hoặc mở file `.md`).
2. Bấm `Ctrl + A` ➔ `Ctrl + C`.
3. Chuyển sang thẻ tương ứng trên Google Docs và bấm `Ctrl + V`.
