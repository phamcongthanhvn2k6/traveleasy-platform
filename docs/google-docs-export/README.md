## 🚀 Hướng dẫn Import vào Google Docs để có giao diện y hệt ảnh mẫu

### Cách 1: Tạo các Thẻ (Document Tabs) trực tiếp trên Google Docs (Khuyên dùng - Nhanh nhất)
1. Mở trình duyệt, truy cập [docs.google.com](https://docs.google.com/) và tạo một tài liệu mới (hoặc mở tài liệu có sẵn của bạn).
2. Nhìn sang thanh menu bên trái, bạn sẽ thấy mục **"Các thẻ và phác thảo" (Tabs & outline)** hoặc biểu tượng **Các thẻ trong tài liệu**.
3. Bấm vào biểu tượng **`+` (Thêm thẻ)** để thêm lần lượt 5 thẻ với tên tương ứng:
   - Thẻ 1: Đổi tên thành `SRS tham khảo`
   - Thẻ 2: Đổi tên thành `SRS thunder deli` (hoặc `SRS TravelEasy`)
   - Thẻ 3: Đổi tên thành `backlog`
   - Thẻ 4: Đổi tên thành `report sprint 1`
   - Thẻ 5: Đổi tên thành `planning sprint 2`
4. Mở từng file `.docx` tương ứng trong thư mục này bằng Word hoặc mở file `.md`, chọn toàn bộ nội dung (`Ctrl + A`) -> Sao chép (`Ctrl + C`) -> Dán (`Ctrl + V`) vào thẻ tương ứng trên Google Docs.
5. Toàn bộ bảng biểu, tiêu đề (Heading 1, Heading 2), gạch đầu dòng, màu sắc và định dạng sẽ được Google Docs giữ nguyên 100%!

### Cách 2: Tải các file `.docx` lên Google Drive
1. Mở [drive.google.com](https://drive.google.com/).
2. Kéo thả các file `.docx` trong thư mục `docs/google-docs-export/` lên Google Drive.
3. Nhấp đúp chuột vào file để mở trực tiếp bằng Google Docs.
